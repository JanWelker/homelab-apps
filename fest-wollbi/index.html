Wollbi-Fescht¶

fest.wollbi.ch is the invitation to the street's summer party, and the archive of every invitation since 1987. It is the same application as Wollbi Adventsfenster, with its own content, built in JanWelker/fest.wollbi.ch (private), so its upstream is our own — per Conventions → Official upstream sources only. This page holds what differs; every other row is on the advent page.

At a glance¶
URL fest.wollbi.ch — public, no login
Authentication Payload signs editors in through Authentik over OIDC, members of wollbi-editors only; no local accounts; /seed redirects to /
Storage A PVC for what editors upload after the seed
Database CloudNativePG Cluster fest-wollbi-db
Secrets kv/fest-wollbi/config, kv/fest-wollbi/seed and kv/fest-wollbi/oidc in OpenBao
Files fest-wollbi/

Configuration¶

Wollbi Adventsfenster → Configuration applies with fest-wollbi for advent-wollbi, except two rows: the media row is the advent site's alone, and fest-wollbi-db runs without a replica (database.yaml), so the single-instance case of Conventions → rule 3 applies and a drain takes the site down for the move.

Seeding¶

The same PostSync hook as Wollbi Adventsfenster → Seeding. On an empty database it imports every file in the site repository's public/seed/images/ as media, including the ones no page references, because the archive is the reason the site exists, then writes three pages: Willkommen, Info and the Einladungsarchiv.

OIDC¶

As Wollbi Adventsfenster → OIDC, with client_id fest-wollbi.

Network policy¶

fest-wollbi/networkpolicy.yaml carries the same rules as the advent site's; the reasons are in Wollbi Adventsfenster → Network policy.

Secrets¶

The three paths in At a glance hold the same keys as Wollbi Adventsfenster → Secrets.

Usage¶

https://fest.wollbi.ch/admin, then as Wollbi Adventsfenster → Editing.

Health check¶

kubectl -n fest-wollbi get pods
kubectl -n fest-wollbi get cluster fest-wollbi-db
kubectl -n fest-wollbi logs job/fest-wollbi-seed
curl -sI https://fest.wollbi.ch/ | head -1

The seed log reads as on Wollbi Adventsfenster → Health check; in Loki it is {namespace="fest-wollbi", container="seed"}.

Pitfalls¶

The Wollbi Adventsfenster pitfalls on the second domain, migrations and restores apply here too. One more:

  • Deleting kv/fest-wollbi/config logs the editors out.
